==============================================================
  Vessel Finder & Anomaly Detection - Syria | Setup Guide
==============================================================

This project pulls real vessel-tracking data from Global Fishing Watch (GFW)
for the Syrian EEZ and runs an unsupervised anomaly-detection model
(Isolation Forest + Local Outlier Factor + rule-based detectors) to flag
vessels exhibiting IUU-fishing / suspicious behaviour:

  - AIS "dark" gaps (vessel switched off its transponder)
  - At-sea encounters / loitering (possible transshipment)
  - Heavy fishing presence inside the EEZ

--------------------------------------------------------------
Step 1 - Get a Global Fishing Watch API token (FREE)
--------------------------------------------------------------
  Each user must use their own personal token. Do NOT share tokens.

  a) Go to https://globalfishingwatch.org/our-apis/
  b) Create a free account and request a non-commercial API access token.
  c) Copy the token string.

--------------------------------------------------------------
Step 2 - Prerequisites
--------------------------------------------------------------
  - Python 3.9 or newer    (https://www.python.org/downloads/)
                           Windows users: tick "Add Python to PATH".
  - git                    (https://git-scm.com/downloads)

  Verify:
    python --version
    git --version

--------------------------------------------------------------
Step 3 - Clone & install
--------------------------------------------------------------
  git clone https://github.com/orarr2/Vessel-finder-and-anomaly-detection-with-GFW-in-Syria.git
  cd Vessel-finder-and-anomaly-detection-with-GFW-in-Syria

  (Optional but recommended - virtual env:)
    python -m venv .venv
    # Windows PowerShell:  .\.venv\Scripts\Activate.ps1
    # macOS / Linux:       source .venv/bin/activate

  pip install -r requirements.txt

--------------------------------------------------------------
Step 4 - Provide YOUR token
--------------------------------------------------------------
  Copy .env.example to .env and paste your token in:

    Windows PowerShell:  Copy-Item .env.example .env
    macOS / Linux:       cp .env.example .env

  Open .env in any editor and set:
    GFW_API_TOKEN=your_token_here

  The .env file is git-ignored, so your token will never be committed.

  Alternative (no .env file) - set it for the current shell only:
    Windows PowerShell:  $env:GFW_API_TOKEN = "your_token_here"
    macOS / Linux:       export GFW_API_TOKEN=your_token_here

--------------------------------------------------------------
Step 5 - Pull real Syria data from GFW
--------------------------------------------------------------
  python fetch_syria.py

  Optional date range / limit (defaults to 2023 full year, 200 vessels):
    python fetch_syria.py --start 2024-01-01 --end 2024-12-31 --limit 1000

  Outputs (written to ./data/, git-ignored):
    data/syria_vessels.csv          - vessels flagged to Syria (registry)
    data/syria_events.csv           - events in the Syrian EEZ
                                      (fishing / encounter / loitering / gap)
    data/syria_fishing_effort.json  - apparent fishing-effort report

--------------------------------------------------------------
Step 6 - Run the anomaly-detection model on YOUR data
--------------------------------------------------------------
  python analyze_syria.py

  Reads the CSVs from Step 5 and writes:
    data/syria_vessel_risk.csv      - per-vessel scores + risk flag

  Prints a console report with:
    - event-type counts
    - Isolation Forest + LOF flagged vessel counts
    - top 15 suspicious vessels (ranked by combined risk score)
    - AIS-gap, encounter and high-loitering breakdowns

--------------------------------------------------------------
Step 7 - (Optional) Open the notebook for full EDA + maps
--------------------------------------------------------------
  jupyter notebook vessel_anomaly_detection.ipynb

  Run cells top-to-bottom. Section 3 pulls the Syria data (token loaded
  from .env), then the rest runs the synthetic-data demo + the same
  Isolation Forest / LOF / DBSCAN ensemble with interactive Folium maps.

--------------------------------------------------------------
Common issues
--------------------------------------------------------------
  "GFW_API_TOKEN not found"     - .env is missing or empty. Re-do Step 4.

  "Host not in allowlist / 403" - your network is blocking
                                  globalfishingwatch.org. Try open internet
                                  or widen the allowlist.

  "422 Unprocessable Entity"    - rate / parameter issue. Re-run with a
                                  smaller --limit.

  pip install errors            - try: python -m pip install -r requirements.txt

--------------------------------------------------------------
Responsible use
--------------------------------------------------------------
  AIS gaps, loitering and zone presence are INDICATORS, not proof. Treat
  flagged vessels as LEADS FOR HUMAN REVIEW. Account for false positives
  (legitimate slow speed, genuine AIS outages, anchorage operations, etc.).

  When you finish, ROTATE your GFW token at the link in Step 1.
